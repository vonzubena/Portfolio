Projects

Here are some projects I've worked on.

// Networking

Small Office Network Design

Designed a network for a 25-person office in Cisco Packet Tracer, with separate VLANs for staff, management and guests, DHCP, inter-VLAN routing and WPA2 wireless. I documented the topology and tested connectivity between segments.

// Programming

Python Project

Built a command-line banking app where users create accounts, deposit, withdraw and transfer funds. Data is saved to JSON files, and input is validated to prevent overdrafts and invalid amounts.

// Security

Linux System Administration

Set up a BIND9 DNS server on Ubuntu with forward and reverse lookup zones. I secured it with SSH key logins and a UFW firewall, and used dig and nslookup to troubleshoot.

// Databases

Database Design Project

Designed a MySQL database for a small retail business, from an ER diagram to a normalized schema (3NF) with primary and foreign keys. I wrote SQL queries for low-stock alerts, monthly sales and top customers.

// Object-Oriented Programming

Python OOP Project

Developed a Python hospital system using classes, inheritance, encapsulation and polymorphism to model patients, doctors and appointments. Users can book and cancel appointments through a menu.

// Web Development

Personal Portfolio Website

Built this four-page portfolio site with HTML5 and CSS3, using fluid design and media queries for phones, tablets and laptops. It includes a validated contact form, an HTML5 video and a cyberpunk theme, and is deployed on GitHub Pages.
